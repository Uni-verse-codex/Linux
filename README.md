# Learning Linux by building devguard 

# a command-line system monitoring tool built from scratch, incrementally across 6 phases.

Each phase adds one layer to the same project: filesystem analysis, log parsing, permissions auditing, process monitoring, network diagnostics, and full bash automation.

# Approach 

struggle-first, docs-only, no tutorials. 

Every concept is learned because the project demanded it , not from a course. 

Phases include intra-phase scenarios (mixing recent concepts) and cross-phase incident simulations modelled on real production problems.

Stack: Bash , Linux CLI , devguard anchor project.

Method: Active recall , spaced repetition and the build → break → rebuild from memory loop.
